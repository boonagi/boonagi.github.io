## 🚀 เริ่มใช้ยังไง (ง่ายมาก 3 ขั้น)

1. เปิด [tedet.partnerx.asia](https://tedet.partnerx.asia) บนเครื่องอะไรก็ได้
2. พิมพ์ชื่อลูกสร้างโปรไฟล์ (เช่น "น้องทันเดอร์")
3. เลือกโหมดที่อยากฝึก — แนะนำให้เริ่มจาก **โหมดติวเข้ม** ก่อน แล้วค่อยขยับไป **ห้องสอบข้อสอบจริง**

> 💡 **เคล็ดลับ:** ให้ลูกทำ "โหมดฝึก" กับข้อสอบจริงปีเก่า ๆ ก่อน (ปี 2557–2560 ง่ายกว่าปีหลัง ๆ) พอคล่องแล้วค่อยจับเวลาสอบจริง 90 นาทีเหมือนสนามจริง

## ❓ คำถามที่พ่อแม่ถามบ่อย

**ฟรีจริงไหม?** — ฟรี 100% ไม่มีค่าใช้จ่าย ไม่ต้องสมัครสมาชิก ไม่มีโฆษณา

**ปลอดภัยไหม ข้อมูลลูกไปไหนหรือเปล่า?** — 🔒 เว็บนี้**ไม่เก็บข้อมูลใด ๆ ขึ้นเซิร์ฟเวอร์** ชื่อโปรไฟล์และคะแนนทั้งหมดอยู่ในเบราว์เซอร์ของเครื่องคุณเท่านั้น

**คะแนนหายไหมถ้าปิดเว็บ?** — ไม่หาย เปิดมาใหม่คะแนนยังอยู่ (แต่ถ้า "ล้างข้อมูลเบราว์เซอร์" หรือเปลี่ยนเครื่อง คะแนนจะไม่ตามไป)

**ข้อสอบมาจากไหน?** — ข้อสอบและเฉลยจริงจากคลังข้อสอบทางการของโครงการ TEDET ([tedet.or.th](https://www.tedet.or.th/main/exam-library.asp)) รวบรวมไว้เพื่อการฝึกฝนศึกษา

**เฉลยวิทยาศาสตร์ทำไมต้องเลือกหลายคำตอบ?** — เป็นกติกาจริงของ TEDET: บางข้อมีคำตอบถูกมากกว่า 1 ข้อ ต้องเลือกให้ครบจึงได้คะแนน เว็บนี้จำลองกติกานี้ให้เหมือนสนามจริง
