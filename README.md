# TEDET Trainer ป.5

เว็บแอปฝึกทำข้อสอบ TEDET (คณิตศาสตร์ + วิทยาศาสตร์) สำหรับ ป.5 — ใช้งานผ่าน GitHub Pages ได้เลย ไม่ต้องติดตั้งอะไร

- `index.html` — แอปหลัก: โหมดฝึกฝน (คำใบ้ + เฉลยละเอียด) และโหมดสอบเสมือนจริง (คลังข้อสอบแนว TEDET 40 ข้อ)
- `exam-math.html` — ห้องสอบข้อสอบจริงคณิตศาสตร์ ย้อนหลังปี 2557–2568 (ภาพข้อสอบ + กระดาษคำตอบดิจิทัล + ตรวจอัตโนมัติ + วิธีทำรายข้อ)
- `exam-sci.html` — ห้องสอบข้อสอบจริงวิทยาศาสตร์ ย้อนหลังปี 2557–2568
- `exam-bank-template.html` + `build-exam-banks.py` — ตัวสร้างไฟล์ห้องสอบ (ฝังภาพ WebP + เฉลย)
- `segment-solutions.py` — ตัดหน้าเฉลยทางการเป็นภาพวิธีทำรายข้ออัตโนมัติ

ข้อสอบและเฉลยเป็นลิขสิทธิ์ของโครงการ TEDET (เผยแพร่สาธารณะที่ [tedet.or.th](https://www.tedet.or.th/main/exam-library.asp)) — รวบรวมไว้เพื่อการฝึกฝนศึกษาส่วนตัว
